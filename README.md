## Wise Tech Frontend
A react app created using vite. Configured theme is Metronics.

## Getting started - Install dependency
```
pnpm install --frozen-lockfile
```

## Start the project in development
```
pnpm run dev
```

## Build the project
```
pnpm run build
```

## Develoment deployment 
Application is hosted on AWS Amplify and is pre-configured with the CI-CD pipleline
