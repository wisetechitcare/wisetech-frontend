yet:** each v2 design is confirmed in Storybook first, then the live component is swapped onto it behind its
existing API (the way `WtButton` now renders the v2 Button).

## Design decisions to confirm

These differ from the live app on purpose. Each needs your yes before the live swap.

1. **Labels sit above fields.** The live kit's floating labels (inside the border) are replaced by shadcn's stacked
   label. It removes the notch bug class `WtField` was rebuilt to fight.
2. **Heading case.** The live house style uppercases structural headings (`HEADING_CASE_SX`); shadcn and the v2
   prototypes use sentence case. Keep uppercase, or move to sentence case?
3. **Category hues.** Seven identity hues (Foundations → Category hues) beside the status set, for leave types,
   departments and modules.
4. **One chart engine:** Recharts via Components/Chart, replacing four chart libraries.
5. **A single value is never a dialog.** `OptionPickerDialog` becomes a Combobox; dialogs remain only for
   multi-select (e.g. picking many employees).
