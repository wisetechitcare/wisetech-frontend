# WiseTech Design System — Visual Language v2

The catalogue of the WiseTech UI kit: owned code on **Radix primitives + Tailwind CSS v4**
(the shadcn model), decided in **ADR-001** (`docs/DESIGN_SYSTEM_DECISION.md`).

## Principles

- **Roles, not colours.** Components use token roles (`primary`, `muted`, `success-soft`…) from
  `src/ds/styles/globals.css` — never a hex value.
- **One meaning per colour.** A single status set (success, warning, danger, info), each with a solid,
  a soft fill and readable text, in light and dark.
- **Apple-inspired, tuned for density.** Apple's structure and materials, with a 14px body and calm
  status tones so data-heavy HR and payroll screens stay readable.
- **Accessible by default.** Radix primitives, visible focus, keyboard-complete; every story is checked
  with axe and fails on a violation.
- **Status is never colour alone.** Badges carry text (and a dot); trends carry an arrow.

## Appearance axes

Use the toolbar above any story:

| Axis | Values | Applied as |
| --- | --- | --- |
| Theme | Light · Dark | `.dark` on `<html>` |
| Surface | Material · Glass | `data-surface` — Glass frosts chrome only; the work canvas stays opaque |
| Density | Comfortable · Compact | `data-density` — compact shrinks the whole spacing scale |
| Brand | WiseTech Navy · Teal · Violet · Graphite | `--brand` — per-tenant brand colour |

## Sections

- **Foundations** — colour roles, status, type scale, radius & elevation, spacing & density.
- **Components** — the Radix + Tailwind primitives in `src/ds/ui`.
- **Patterns** — page header, stat card, empty state (`src/ds/patterns`).
- **Screens** — prototypes of the new app shell and hero screens (`src/ds/prototypes`).
