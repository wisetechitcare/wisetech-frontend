# WiseTech Design System — Visual Language v2

The catalogue of the WiseTech UI kit: owned code from **shadcn/ui** (style `base-maia`) on
**Base UI + Tailwind CSS v4**, with **React Aria** for locale-sensitive inputs (dates, times, numbers).
Decided in **ADR-001** (`docs/DESIGN_SYSTEM_DECISION.md`).

## Principles

- **Roles, not colours.** Components use token roles (`primary`, `muted`, `success-soft`…) from
  `src/ds/styles/globals.css` — never a hex value.
- **One meaning per colour.** A single status set (success, warning, danger, info), each with a solid,
  a soft fill and readable text, in light and dark.
- **shadcn's design, our colours.** Components come from the shadcn CLI unchanged in shape, type and
  motion; only the colour roles (navy brand, status set, per-tenant brand) are ours.
- **Accessible by default.** Base UI and React Aria primitives, visible focus, keyboard-complete; every story is checked
  with axe and fails on a violation.
- **Status is never colour alone.** Badges carry text (and a dot); trends carry an arrow.

## Where we differ from stock shadcn

Everything in `src/ds/ui` comes from the shadcn CLI (`components.json`, style `base-maia`). Our only
changes, each marked in the file:

- **Badge** — the WiseTech status set (`success`, `warning`, `danger`, `info`, `brand`, `neutral`) and `dot`.
- **Button** — the live app's button physics: gradient + own-colour glow on filled buttons, 1px lift on
  hover, press to 0.975, spring easing (motion only when the user allows it).
- **Toaster** — follows our light/dark engine instead of `next-themes`.
- **cmdk** (behind Command) — patched for three screen-reader bugs; see `pnpm-workspace.yaml`.

Screens and patterns are composed only from these components; `src/ds/consistency.test.ts` fails the
build if one hand-builds a button, input, textarea, kbd or card.

## Appearance axes

Use the toolbar above any story:

| Axis | Values | Applied as |
| --- | --- | --- |
| Theme | Light · Dark | `.dark` on `<html>` |
| Surface | Material · Glass | `data-surface` — Glass frosts chrome only; the work canvas stays opaque |
| Density | Comfortable · Compact | `data-density` — compact shrinks the whole spacing scale |
| Brand | WiseTech Navy · Teal · Violet · Graphite | `--brand` — per-tenant brand colour |
