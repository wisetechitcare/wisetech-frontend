Time picker dialog transition

Five layers, staggered. The enter is slow and expressive at 500 ms; the exit is 150 ms and gets out of the way. Driven by the Web Animations API so both directions can be awaited and interrupted — open the dialog and dismiss it mid-flight.

The surface unfolds, the layout doesn't

The height grow runs on .container::before, not the container. The real box keeps its final size the whole time, so the clock face is never squashed or reflowed — it just fades in late over a surface that is still opening.

Hold-then-fade, not delay

Headline and content hold at opacity: 0 through the first 20% of their own 250 ms, actions through the first 50% of 300 ms. Three-stop keyframes, so the stagger scales with the animation instead of drifting from it.

Close awaits, then unmounts

Scrim, Escape, Cancel and OK all run the same exit. Visibility is only dropped after animation.finished resolves — and a reopen mid-exit cancels it cleanly rather than queueing behind it.
